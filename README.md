# Backgammon Coach

Play backgammon against GNU Backgammon's neural network with a coach that grades every move (GNU looking 2 rolls ahead), shows the better play on the board, and tracks win chances. Works fully offline once added to the iPhone home screen (Safari → Share → Add to Home Screen).

## Credits and licence
The evaluation engine is a JavaScript port of the static evaluation of [GNU Backgammon](https://www.gnu.org/software/gnubg/) 1.07 (neural-net weights, one-sided bearoff database and race-backgammon tables included in `index.html`).
